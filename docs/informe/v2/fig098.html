Referencias entre contextos

Todos los agregados guardan ownerAdminId: referencia por id al condominio, una cuenta User de IAM (solo Profiles y Billing la dibujan arriba). Los contextos se comunican por servicios de aplicación y ACL, no por asociaciones entre clases.
